This is the first release of AmpGhost, the Linux editor I use every day with my own Katana 50 MK II.

- Live connection to the Katana 50 MK II over USB, with automatic reconnect when the amp comes back
- Editing of the signal chain blocks in the amp's temporary patch, verified by reading them back
- Channel switching between Panel, A1, A2, B1 and B2
- Local presets on your computer
- Import and export of BOSS TONE STUDIO `.tsl` livesets
- Automatic backup of the temporary patch before a preset, an imported tone or a reloaded channel replaces it

AmpGhost only writes to the temporary patch. It never stores to the amp's channels or changes system settings.

Download `ampghost-0.1.0-x86_64.flatpak` below and install it:

```sh
flatpak install --user ampghost-0.1.0-x86_64.flatpak
```

To update from an earlier version, install the new bundle over it. Your presets and backups are kept:

```sh
flatpak install --user --reinstall ampghost-0.1.0-x86_64.flatpak
```

More details, including how to uninstall, are in the [README](https://github.com/janick-foundry/ampghost#installation).
