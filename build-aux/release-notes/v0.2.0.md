AmpGhost now follows the amp: when you turn a knob on the Katana 50 MK II, the app shows the new value.

- Knob changes made on the amp appear in the app. AmpGhost puts the amp in editor mode when it connects
- Editor mode is switched off again when AmpGhost closes, also when it is stopped with Ctrl+C or by the system
- The About dialog shows the commit the build was made from, and its troubleshooting information also shows the build time
- Error messages show the whole chain of causes instead of only the last one
- The status pages use icons bundled with the app, and the symbolic app icon shows the ghost

AmpGhost only writes to the temporary patch. It never stores to the amp's channels or changes system settings.

Download `ampghost-0.2.0-x86_64.flatpak` below and install it:

```sh
flatpak install --user ampghost-0.2.0-x86_64.flatpak
```

To update from an earlier version, install the new bundle over it. Your presets and backups are kept:

```sh
flatpak install --user --reinstall ampghost-0.2.0-x86_64.flatpak
```

More details, including how to uninstall, are in the [README](https://github.com/janick-foundry/ampghost#installation).
